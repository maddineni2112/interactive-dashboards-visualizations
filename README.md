# Interactive Dashboards and Visualizations

**Timeline:** November 2025  
**Category:** Main project

This project implements reusable interactive visualizations for line charts, scatter plots, geographic views, and hierarchical data. The webpages demonstrate linked visual encodings, SVG/TopoJSON rendering, and browser-based exploration.

## Stack

HTML/CSS, JavaScript, D3.js, Altair, Vega-Lite, TopoJSON, d3-geo, d3-hierarchy, SVG, Plotly, Python, and Pandas.

## Repository contents

- `web/` — standalone visualization pages.
- `reports/` — visualization project report.
- `data/README.md` — source and excluded-data notes.
